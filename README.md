# Pinboard

마음에 드는 장면을 발견하고 나만의 보드에 모으는 Pinterest 스타일 프론트엔드 데모입니다. React · TypeScript · Vite · React Router · IndexedDB로 구현했습니다. 한국어 UI와 모바일·태블릿·데스크톱 레이아웃을 제공합니다.

## 실행과 검증

Node.js 22.12 이상(22.x, 24.x, 26 이상)과 npm이 필요합니다.

```bash
npm ci
npm run dev
```

터미널에 표시된 로컬 주소를 여세요. 기본 주소는 `http://127.0.0.1:5173`입니다.

```bash
npm run typecheck
npm test
npm run build
npm audit
node scripts/verify-history.mjs
```

배포용 파일은 `dist/`에 생성됩니다. 호스팅은 포함하지 않습니다. 추후 정적 호스팅 시 모든 앱 경로를 `index.html`로 연결하는 SPA fallback이 필요합니다. 개발 서버는 localhost에만 바인딩합니다.

## 할 수 있는 일

- 이미지 60개의 masonry 피드, 카테고리 필터, 18개 단위 추가 로딩.
- 제목·설명·태그 검색, URL에 검색어와 카테고리 보존.
- 핀 상세, 이미지 확대, 작가·출처 링크, 태그 기반 관련 핀.
- 보드 생성·이름 변경·삭제, 여러 보드에 핀 저장·해제, 중복 저장 방지.
- 이미지 업로드·미리보기, 만든 핀의 생성·수정·삭제.
- 프로필에서 만든 핀과 저장한 보드 확인.
- 키보드 탐색, 본문 건너뛰기, 네이티브 dialog 포커스 제한·복원·Esc 닫기.

## 데이터와 이미지

로그인 없는 단일 데모 사용자입니다. 핀·보드·저장 관계와 업로드 Blob은 현재 origin의 IndexedDB `pinboard`에 저장됩니다. 새로고침 후에도 유지되지만 브라우저 사이트 데이터를 지우거나 다른 기기·포트·호스트에서 접속하면 같은 데이터를 볼 수 없습니다. 내보내기·서버 동기화는 제공하지 않습니다. 브라우저의 저장 정책에 따라 데이터가 정리될 수도 있습니다.

JPEG·PNG·WebP, 최대 10MB의 읽을 수 있는 이미지를 받습니다. 업로드 사진은 서버로 전송하지 않습니다. 저장 실패는 성공으로 표시하지 않으며, 저장 공간 부족은 삭제 후 재시도를 안내합니다. 보드를 삭제해도 원본 핀은 유지되고, 직접 만든 핀을 삭제하면 모든 보드의 해당 저장 관계도 제거됩니다.

샘플 사진은 Lorem Picsum이 제공하는 Unsplash 사진입니다. 로컬 파일로 포함했으며 [사진별 작가·출처](docs/image-credits.md)와 [Unsplash 라이선스](https://unsplash.com/license)를 기록했습니다. 코드의 MIT 라이선스는 사진에 적용되지 않습니다. 글꼴은 Google Fonts에서 로드하며 네트워크가 없으면 시스템 글꼴을 사용합니다.
